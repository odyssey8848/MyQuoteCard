# 隐私说明 / Privacy

## 中文

自言卡不会连接互联网，不包含广告、账号系统、分析工具或遥测功能，也不会收集或上传任何个人信息。

用户的内容库、外观设置和窗口位置只保存在本机 `%LOCALAPPDATA%\MyQuoteCard`。如果用户选择开机自启动，软件只会在当前 Windows 用户的启动项中写入自言卡 EXE 的路径。

背景图片会被复制到上述本地数据文件夹。用户在报告问题时，应自行检查截图和 `quotes.txt`，避免公开私人内容。

## English

MyQuoteCard does not connect to the internet. It contains no ads, accounts, analytics, or telemetry, and it does not collect or upload personal information.

The content library, appearance settings, and window position are stored only in `%LOCALAPPDATA%\MyQuoteCard`. If launch-at-startup is enabled, the app writes only its EXE path to the current Windows user's startup entry.

Selected background images are copied to the same local data folder. Before reporting an issue, users should review screenshots and `quotes.txt` to avoid sharing private content.
